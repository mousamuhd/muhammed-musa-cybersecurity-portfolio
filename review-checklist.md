# Linux Log Review Checklist

- [ ] Confirm the Linux distribution and version.
- [ ] List the available files under `/var/log`.
- [ ] Identify which log files are relevant to the exercise.
- [ ] Review a small, recent sample of entries.
- [ ] Record timestamps and event messages accurately.
- [ ] Follow a log in real time if appropriate.
- [ ] Distinguish observed facts from assumptions.
- [ ] Redact sensitive information before saving screenshots.
- [ ] Record the exact commands actually used.
- [ ] Note any limitations or missing evidence.

Do not label an event malicious without sufficient context and corroborating evidence.
